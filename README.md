# EV TECH
سایت آموزشی خودروهای برقی با HTML/CSS/JS خالص؛ بدون بک‌اند.
## انتشار روی GitHub Pages
1. مخزن جدید در GitHub بسازید.
2. چهار فایل index.html، style.css، script.js، data.js و README.md را آپلود کنید.
3. Settings ← Pages ← Source: Deploy from a branch ← main / root ← Save.
4. چند دقیقه بعد، سایت در `https://USERNAME.github.io/REPO/` آماده است.
## نکته
فونت Vazirmatn از CDN بارگذاری می‌شود؛ در نبود اینترنت از Tahoma استفاده می‌شود. مقادیر نامعلوم عمداً «اطلاعات تأییدشده در دسترس نیست» نمایش داده می‌شوند.
## منابع تصاویر
تصاویر خودروها در پوشه images قرار دارند. نام عکاس و مجوز هر تصویر را (در صورت CC BY / CC BY-SA) اینجا اضافه کنید.

## منابع داده
مشخصات از Porsche Newsroom، بروشور BYD، EPA (از طریق Edmunds/InsideEVs/Green Car Reports)، Hyundai، و پایگاه‌های EV Database، ArenaEV و EVKX گردآوری شده است. هر عدد غیررسمی در یادداشت همان خودرو مشخص شده است.
